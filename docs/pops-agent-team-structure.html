🛡 Nothing is Deleted — Safety Plan

  • Git tracks all history — every original .md is recoverable via git log --all -- .claude/agents/
  • Step 1: git add .claude/agents/ && git commit -m "snapshot: 26 agents" — not needed. Verified 2026-07-29: all three working trees are clean and all agents are already tracked (26 / 26 / 6 in git ls-files). The current HEAD already IS the snapshot; that command would produce an empty commit.
  • Run the snapshot in BOTH repos — there are THREE git repos, not two. clinic/atlas has its own remote (clinic/atlas.git), so following the original wording would have modified atlas with no snapshot of its own — the one place "Nothing is Deleted" would have slipped.
  • Merged agents take BEST content from each source — nothing valuable is dropped
  • If any merged agent is wrong: git show HEAD~1:.claude/agents/original-name.md restores it
  • Backup branch: git branch agents-backup-26 — redundant on a feature branch. If the work lands on chore/agent-merge, the pre-merge commit stays reachable from prototype/main and can never be GC'd. Rollback is git checkout prototype. A backup branch buys a memorable name, not safety.
