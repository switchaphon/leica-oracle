Usage — measured, not guessed
Method. Four anchored capture patterns, intersected with the real skill list — never bare-name matching, which false-positives on skills named go, run, review:
  • <command-name>/X</command-name>
  • "skill":"X"
  • Launching skill: X
  • skills/X/SKILL.md
Confidence ≈85%. A skill invoked without leaving any of those four markers is undercounted. Scanner lives at ψ/lab/skill-census-2026-07-29/census2.py, runs in ~2.8s, re-runnable. Use clean.json — census2.json contains self-contamination.
Nothing is merely new. Of the 96 never-called skills, the most recently added has been untouched since 2026-06-19. Non-use is not a warm-up period.

⚠ Why "consolidate the similar ones" is dangerous without measurement

A proposed merge of dig into trace looked obvious on paper. Measured: dig = 10 calls / 9 sessions, trace = 2 calls / 1 session. The merge would have deleted the skill used 5× more and kept the quieter one. Reverted. Measure before merging, every time.

Why unused skills are not free
A skill that is never invoked still ships its name and description into the system prompt of every session. 96 skills nobody has called since 2026-06-19 are therefore paid for on every session, of every Oracle, every day — 18 Oracles wide. That recurring cost, not tidiness, is the argument for acting.

Counting traps hit while producing this
Four count discrepancies during the census. None was a tool bug:
  • 120 vs 75 skills — symlinks. find -type d does not follow them, os.path.isdir() does. Both counts correct.
  • 26 vs 27 inbox files — measured an hour apart; a file was written in between.
  • 644 vs 26 agents — the 644 were agent worktrees, not agent definitions.
  • 188 vs 182 plugin skills — glob('**') skips dotted dirs. Here rtk proxy was right and the "native" check was wrong.
Before calling a count a bug, ask: different semantics? different time? different objects? A positive control proves a tool can return hits — it never proves the count is complete. Only agreement between two independent methods establishes a number.
