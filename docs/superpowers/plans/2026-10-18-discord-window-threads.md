# Discord Threads per tmux Window Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A plain-code bridge that gives each tmux window of an oracle its own Discord thread, carries Un's thread messages into that window as written, and posts the window's words back in a form that reads on a phone. pops-vet first, window 1 first.

**Architecture:** A Python program (standard library only) runs in a second pane of the bot window. It talks to Discord over REST with the bot's token, reads tmux screens to know when a window is idle, busy or asking, reads the Claude transcript for the exact markdown, and pastes into panes with tmux. The Discord plugin keeps the DM and shared channels, and is configured never to take `#pops-vet` messages.

**Tech Stack:** Python 3.11+ stdlib (`urllib`, `json`, `subprocess`, `unittest`), tmux 3.6, headless Google Chrome for images, bash for `bot-up.sh`.

**Spec:** `docs/superpowers/specs/2026-10-17-discord-window-threads-design.md` (approved 2026-10-18). Read it before any task.

**Where to work:** Tasks 1-11 in a worktree of leica-oracle on branch `feat/discord-window-threads` (superpowers:using-git-worktrees). Tasks 12-15 change pops-vet-oracle and the live tmux session, and run inline with Un, not in a subagent.

```python
import io, json, unittest, urllib.error
from discord_api import Discord, DiscordError

class Resp(io.BytesIO):
    def __enter__(self): return self
    def __exit__(self, *a): pass

def err(code, body):
    return urllib.error.HTTPError("u", code, "x", {}, io.BytesIO(json.dumps(body).encode()))

class Opener:
    def __init__(self, *responses): self.responses, self.requests = list(responses), []
    def __call__(self, req, timeout=None):
        self.requests.append(req)
        r = self.responses.pop(0)
        if isinstance(r, Exception): raise r
        return Resp(r if isinstance(r, bytes) else json.dumps(r).encode())

def client(op, slept=None):
    return Discord("T", opener=op, sleep=(slept.append if slept is not None else (lambda s: None)))

class TestDiscord(unittest.TestCase):
    def test_send_never_pings_and_authenticates(self):
        op = Opener({"id": "9"})
        client(op).send("C", "hi <@1>")
        self.assertEqual(json.loads(op.requests[0].data)["allowed_mentions"], {"parse": []})
        self.assertEqual(op.requests[0].get_header("Authorization"), "Bot T")

    def test_429_waits_retry_after_then_succeeds(self):
        slept = []
        op = Opener(err(429, {"retry_after": 0.25}), {"id": "9"})
        self.assertEqual(client(op, slept).send("C", "hi")["id"], "9")
        self.assertEqual(slept, [0.25])

    def test_429_gives_up_after_five_tries(self):
        op = Opener(*[err(429, {"retry_after": 0}) for _ in range(5)])
        with self.assertRaises(DiscordError):
            client(op).channel("C")

    def test_archived_thread_is_reopened_once(self):
        op = Opener(err(400, {"code": 50083, "message": "Thread is archived"}), {"id": "T1"}, {"id": "9"})
        client(op).send("T1", "hi")
        self.assertEqual([r.get_method() for r in op.requests], ["POST", "PATCH", "POST"])
        self.assertEqual(json.loads(op.requests[1].data), {"archived": False})

    def test_files_go_multipart(self):
        op = Opener({"id": "9"})
        client(op).send("C", "x", files=[("table.png", b"PNG", "image/png")])
        req = op.requests[0]
        self.assertTrue(req.get_header("Content-type").startswith("multipart/form-data; boundary="))
        self.assertIn(b'name="files[0]"; filename="table.png"', req.data)
        self.assertIn(b'"filename": "table.png"', req.data)

    def test_create_thread_is_public_with_week_archive(self):
        op = Opener({"id": "T1"})
        client(op).create_thread("C", "1:pops-vet")
        self.assertEqual(json.loads(op.requests[0].data), {"name": "1:pops-vet", "type": 11, "auto_archive_duration": 10080})

    def test_messages_after_returns_oldest_first(self):
        op = Opener([{"id": "3"}, {"id": "2"}])
        self.assertEqual([m["id"] for m in client(op).messages_after("C", "1")], ["2", "3"])
        self.assertIn("after=1", op.requests[0].full_url)

    def test_empty_body_is_none(self):
        self.assertIsNone(client(Opener(b"")).typing("C"))
```

The secret pattern, copied verbatim from the old relay:

```python
SECRET = re.compile(
    r"(glpat-[\w-]{16,}|gh[pousr]_[A-Za-z0-9]{20,}|github_pat_\w{20,}|xox[abprs]-[\w-]{10,}"
    r"|sk-[A-Za-z0-9_-]{20,}|AKIA[0-9A-Z]{16}|eyJ[\w-]{10,}\.[\w-]{10,}\.[\w-]{10,}"
    r"|[MN][A-Za-z\d]{23,27}\.[\w-]{6}\.[\w-]{27,}|Bearer\s+[\w.-]{16,}"
    r"|(?i:(?:password|passwd|secret|token|api[_-]?key)\s*[=:]\s*)\S{6,})"
)
```

`redact` replaces each match with `[REDACTED]`. `to_posts` redacts first.

`to_posts` walks the lines once and sorts them into segments:
- table: a `|` line followed by a separator line matching `^\s*\|?\s*:?-{2,}:?\s*(\|\s*:?-{2,}:?\s*)*\|?\s*$`, outside any fence
- layout: an unlabelled fence (` ``` ` with nothing after it) with at least one line matching `\S {2,}\S`
- code: any other fence, kept as written
- text: everything else

Split a table cell row on `|` that is not inside backticks. `\|` is a literal pipe.

Text accumulates in a buffer:
- Headings `^#{1,6} (.*)` become `**\1**`.
- Horizontal rules become blank lines.
- Three or more newlines collapse to two.

A table flushes the buffer as `Post(buffer, [("table.png", png, "image/png")])`, then appends `cards()` to the buffer. If the renderer returns `None`, it appends only the cards.

A layout flushes the buffer as `Post(buffer, [("layout.png", png, "image/png"), ("layout.txt", raw_text, "text/plain")])`. If the renderer returns `None`, the fence stays in the buffer as code.

At the end, chunk the buffer. A flushed buffer longer than `LIMIT` becomes chunks, and only the last chunk carries the files. `lead`, when given, is prepended with a newline to the first post's text.

`chunk` splits on blank lines outside fences and packs paragraphs up to `limit`. A paragraph longer than `limit` is cut at the last newline or space past half the limit, otherwise hard-cut. A cut must never land inside a fence: close it with ` ``` ` and reopen it with the same opening line in the next chunk.

`turn_posts`:
- `text = "\n\n".join(texts)`
- `lead = "" if from_discord or prompt is None else MAC_LEAD + "\n> " + prompt_preview(prompt)`
- If `len(text) > LONG_TURN`, return `to_posts(final, r, lead joined with LONG_LEAD)` and attach `("turn.md", text.encode(), "text/markdown")` to the last post.
- Otherwise return `to_posts(text, r, lead)`.

`prompt_preview` drops `<...>` tags, collapses whitespace, and cuts to `limit` with `...` appended (three periods, never the ellipsis character).

This is a port of the state reader in the old `relay.py`. A copy is in Leica's session scratchpad at `ref/relay.py` if it still exists. The patterns are tuned to Claude Code 2.1.288-2.1.302:

```python
DONE = re.compile(r"^\S .+ for \d.* · done \d{1,2}:\d{2}\s*$")
BUSY = re.compile(r"esc to interrupt")
SPINNER = re.compile(r"^\S \S[^(]*… \(")
PROMPT_UI = re.compile(r"Enter to select|Do you want to |↑/↓ to navigate|Esc to cancel")
LIMIT = re.compile(r"Usage limit reached|hit your session limit")
BOX = "│╭╮╰╯"
```

Algorithm:

```
lines = rstripped lines, trailing blank lines dropped
border(i) = lines[i].count("─") >= width * 0.5
B = indices of border lines
top, input = len(lines), ""
if len(B) >= 2 and the line after B[-2] starts (after spaces) with "❯" or ">":
    top = B[-2]
    input = box text between B[-2] and B[-1], first line without its "❯ "/"> ", rest stripped, joined by "\n", stripped
content, near, tail = lines[:top], last 12 lines of content, last 30 lines of all
dones = indices in content matching DONE; after = content after the last done
turn_open = any line in after starts with "❯ " and none contains "Interrupted"
prompt  if PROMPT_UI matches tail and top == len(lines)
busy    elif BUSY matches near, or SPINNER matches a line of near, or turn_open
limit   elif LIMIT matches near
idle    elif dones or "❯" in tail
unknown otherwise
```

`prompt_lines`, for `prompt`:
- Let `m` be the first line matching `PROMPT_UI`.
- If `m` is below the last border and there are at least two borders, take the lines strictly between `B[-2]` and `B[-1]`.
- Otherwise take the lines after the last border above `m`, through the end.
- Strip whitespace and `BOX` characters from both ends of each line, and drop empty lines.

For `limit`, `prompt_lines` is the last 15 non-empty content lines with `BOX` stripped.

`hash`:
- `region` is `prompt_lines` for `prompt`, otherwise `content`.
- `flat = re.sub(r"[\s│├┼└┌┐┘┤┬┴─╭╮╰╯]+", "", "".join(region))`
- `done` is the `HH:MM` of the last done line, or `""`.
- `hash = sha1(f"{state}\n{done}\n{flat[-150:]}").hexdigest()[:10]`

`Tmux` commands:
- `windows`: `list-windows -t S -F "#{window_index}\t#{window_id}\t#{pane_id}\t#{window_name}"`

- `paste`:

  2. `paste-buffer -p -d -b bridge -t <pane>`
  3. `sleep(1.0)`
  4. `send-keys -t <pane> Enter`
- `keys`: one `send-keys -t <pane> <key>` per key, with `sleep(0.4)` between them

`safe_send`:
1. Recapture and parse.
2. Refuse, in this order:
   - state is not `idle`: `"not idle"`
   - the input box has text: `"input box has text"`
   - the hash differs from `expected.hash`: `"changed"`
3. Paste.
4. Poll up to `wait_s` times, one second apart, for `busy`, or for an empty input box with a hash that has changed. Either one is `"ok"`. When the polls run out, return `"not submitted"`.

`safe_keys` uses the same refusal checks with `prompt` in place of `idle`, then sends the keys.

- [ ] **Step 3: Implement the inbound half of `tick()` and `main()`**

Part two of `tick()`, after outbound:

4. **Fetch.**
   - Call `active_threads(guild)` once.
   - For each mapped thread, and for the main channel through `channel(id)`, compare `last_message_id` with `last_seen`. Any difference means new messages; the bridge's own posts count too and are then ignored by `route`.
   - Call `messages_after(id, last_seen)` and `route` each message:
     - `ignore`: skip it.
     - `closed`: send `CLOSED` once, recorded as `marks[msg] = "closed"`.
     - `window` or `bot`: append `asdict(Incoming)` to `queue[target]`, with `arrived = clock()`.
   - Set `last_seen` to the id of the last message fetched.
5. **Deliver,** per queue target. The target is a window id, or `"bot"`.
   - The pane is the window's pane (or `bot_pane`).
   - A queued window whose mapping has closed gets `CLOSED` once, then the queue is dropped.
   - A window with no Claude session gets `NOT_CLAUDE` once, then the queue is dropped.
   - Otherwise call `decide(parse(capture), msgs, clock() - newest arrival)`:
     - `deliver`:
       1. Download attachments to `<state_dir>/inbox/<message_id>-<filename>`.
       2. Build the text: `compose` for a window, or the `channel_tag` lines joined by `"\n\n"` for `"bot"`.
       3. Call `safe_send`. On `"ok"`:
          - Remove ⏳ wherever `marks[m] == "wait"`, and add ✅.
          - Set `delivered[target] = {"text": text, "at": clock()}`.
          - Clear the queue.
       4. On any other result, log it and keep the queue.
     - `keys`: `safe_keys` with the digit, then ✅.
     - `ask_number`: send `ASK_NUMBER` once per message, recorded as `marks[m] = "asked"`. The message stays queued.
     - `wait`: add ⏳ once, recorded as `marks[m] = "wait"`. Skip it when the window is idle with an empty input box, because then the only reason is the few-second grace, and a ⏳ that flips to ✅ a moment later is noise.
6. **Typing.** For each window whose `delivered` entry is under 30 minutes old and whose screen is `busy`, call `typing(thread)` at most once every 8 seconds.
7. **Save** state.

`main()` checks things in this order:
1. The token comes from `env["DISCORD_BOT_TOKEN"]`. Empty means print `no DISCORD_BOT_TOKEN: start the bridge from the bot window` and return 2.
2. The pidfile is `<state_dir>/bridge.pid`. A live pid in it means return 1. Otherwise write our own pid, and remove the file on exit and on SIGTERM or SIGHUP.
3. Only then load the config.

After that:
- Log to stdout and to `<state_dir>/bridge.log`, which rotates to `bridge.log.1` at 5 MB.
- After `start()`, print `bridge: ready as <username>, watching <session>`.
- The loop: reload `Config` when the mtime of `bridge.json` changes, run `tick()` under `try/except` that logs, then sleep `poll_seconds`.
- `--once` runs one tick and returns 0.
- The default factory builds `Discord(token)`, `Tmux()` and `Renderer(cfg.chrome, <state_dir>/render)`.
- `own_pane` comes from `env["TMUX_PANE"]`.
