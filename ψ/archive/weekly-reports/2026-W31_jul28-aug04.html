Lessons worth keeping

Read the value; do not measure it.Length and entropy classified a self-describing placeholder as a live credential and triggered a three-month "public leak" alarm that was never real. Reading the string would have settled it in five seconds.
A positive result proves itself; only absence needs a control."I found nothing" proves nothing until the test is shown capable of finding something.
Exit 0 is the actor's own testimony.A command reported delivery and wrote nothing — four times before anyone checked the far end instead of the return code.
Liveness is not freshness.A component that answers is not a component that works — one table sat frozen eight days while every health check stayed green.
The detector's blind spot becomes the cleanup's blind spot.A credential survived its own removal commit because the scanner verifying the cleanup could not see that pattern.
Recovery erases the evidence.A system that heals itself destroys the state you needed to explain the failure. Capture first, restore second.
Test on real data, not on the harness.Two tools passed every local test and failed immediately on the real cluster. Neither failure was reachable from the test rig.
