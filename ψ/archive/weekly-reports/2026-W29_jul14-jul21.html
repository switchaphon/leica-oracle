Key Learnings

Build-once-promote — CI/CD redesign: shared ci-templates repo, 3-lane pipeline, dotenv artifacts for cross-stage image reuse. Except Next.js NEXT_PUBLIC_* which requires rebuild-at-promote (ADR 0005).
Per-platform Infisical identity — group-level Infisical identity gets inherited silently; each app needs its own identity to avoid 403→empty→JSONDecodeError cascade.
Verify the real path, not proxy signals — deploy-night documented 6 "liars" (green CI ≠ working app, curl ≠ browser, DNS cache ≠ live resolution). Always verify the actual user path end-to-end.
Prod K8s topology: evidence over convention — SSD node as control plane (fio-gated), asymmetric hardware is fine when you measure. Self-caught flannel→Calico CNI mistake via /rrr --deep BEFORE execution.
Backup plane: verify artifacts, not just status — restore drill passed (64/256 rows, 156 images). Script re-discovers PV paths each run (distroless pods → no tar inside container).
Species/breeds master reconciliation — composite identity across 3 DBs, cultural nuance in Thai animal naming, reconciliation plan as prerequisite for data integrity.
Verify reality over memory — Oracle invented env vars and confident-wrong calls about filesystem paths. Pattern: read the artifact before answering.
