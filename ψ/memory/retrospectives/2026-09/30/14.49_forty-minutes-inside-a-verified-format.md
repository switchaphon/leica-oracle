import json, os, subprocess, sys
from datetime import datetime
from zoneinfo import ZoneInfo

BKK = ZoneInfo("Asia/Bangkok")
SCRIPT = "/Users/switchaphon/.claude/runcat-statusline.py"

def ts(y, mo, d, h, mi):
    return int(datetime(y, mo, d, h, mi, tzinfo=BKK).timestamp())

    "on the hour": {"five_hour": {"used_percentage": 35, "resets_at": ts(2026, 9, 30, 16, 0)},

for name, rl in cases.items():
    env = dict(os.environ, CLAUDE_TOKEN_NAME="kla", RUNCAT_OUT_FILE=OUT, TZ="Asia/Bangkok")

    rows = " | ".join(f"{m['title']}: {m['formattedValue']}" for m in snap["metrics"])

## Lessons Learned

- **A round sample cannot test a truncation.** `%-I%p` drops minutes; `1788447600` has none. Test a lossy transform on an input that contains what it could lose: a non-zero minute, midnight, cap + 1.
- **A shared function is verified per input population, not per function.** One formatter, two callers. Verifying the 7d row let "verified" cover the 5h row, which was the one that was wrong. The sample with the free answer key picks itself; pick the other one too.
- **Synthetic proves the code, live proves the world.** The 16:37 case proved the new format keeps minutes. Only the live payload showed the real data has minutes, which is what made the old format wrong rather than coarse.
- **A format is a precision claim.** `4PM` reads as "at four". Same family as commit `3606452` from 2026-09-05: a JPEG cut at the read cap begins exactly like a whole one, and a time cut to the hour reads exactly like a whole time. Two silent truncators in one month.
- **RTK's `diff` is positional.** One inserted line turns every later line into a change. Its counts are not evidence; use `rtk proxy diff -u`.
