## Architecture Decisions

1. **Explicit token lines, not `source_up`.** `source_up` would have worked, but the 7 healthy
   repos already use explicit three-line blocks and `maw token use` writes exactly that. A
   second pattern in a uniform setup costs more than it saves.
2. **`~/.envrc` removed rather than repointed.** It silently made every directory under `$HOME`
   default to `por` — which is why `maw token scan` listed `~` as if it were an oracle. Removing
   it makes the tokenless case *loud* instead of silently wrong.
3. **A guard in `~/.zshrc`, because a rule you have to remember is not a fix.** Its honest limit
   is recorded: `.zshrc` is sourced by interactive zsh only, not scripts, cron, or `zsh -c`.
4. **Keychain deleted as defense-in-depth, explicitly not as the fix** — the commit message says
   so outright, because a future reader would otherwise misread `c86adba` as the cure.
5. **`docs/` is now the record for plans deliberately not executed** — status badge, re-validation
   date, Un's decision quoted, superseded steps struck through rather than deleted.

## Lessons Learned

1. **Verify a binary against its release, never against its source tree.**
   `maw --version` vs `gh release list`, then `git merge-base --is-ancestor <fix-sha> <tag>`.
   `git pull` on a repo you do not build proves nothing.
2. **direnv loads only the nearest `.envrc` and does not merge with parents.** A one-line
   `.envrc` for an unrelated variable silently drops every credential you thought was inherited.
3. **Two unrelated-looking symptoms with no shared code path is evidence *for* a version problem.**
4. **`ps` decides what is running; config files only state intent.** Grep the *whole* config for
   duplicate entries of the same name before trusting the first block you find.
5. **Order matters in auth flows.** `claude setup-token` writes `oauthAccount` exactly like
   `/login`. Run it *before* removing the field or you silently undo the fix and burn the test.
6. **A malformed credential fails silently and can display another account's numbers.**
   Acceptance test, every time: `pass show claude/token-<n> | wc -c` == 109, prefix matches, no
   whitespace. And `pass insert -m` answered-then-aborted **wipes the entry**.
7. **Never verify an action with the tool that performed it.** `ps | grep -c` returned 0 while
   `pgrep` found two live processes. Treat a zero from a grep pipeline as unproven, not absent.
8. **Wrong memory is worse than no memory** — it stops you looking. This one cost two days.
